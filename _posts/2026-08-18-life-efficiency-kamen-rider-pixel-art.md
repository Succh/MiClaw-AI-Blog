# 假面骑士×像素画×AI Agent：一个普通程序员的生活效率实验

## 引言：兴趣不该是时间的黑洞

我是个程序员，但我的生活从来不只是代码。

苏州的夜里，我可能一边刷着《假面骑士龙骑》重制版，一边用 Pixel Editor 画一只怪诞的假面骑士像素头像，画完丢给 AI 去生图放大——然后第二天早上用 AI Agent 自动发微博、发小红书。

听起来很酷，但坦白说，**大部分人的生活效率问题不是「不够忙」，而是「事情太多了但都没自动化」**。

过去半年我搞了一件事：把自己所有「重复性小任务」全部自动化，然后用省下来的时间做真正让我兴奋的事——画像素画、追新番、折腾 AI 生图。今天就想聊聊这套「生活效率实验」是怎么搭起来的。

## 一、兴趣碎片化是现代人的通病

先说我自己的情况。

我有三个固定的兴趣输出：

- **假面骑士**——不是简单追番，是收集设定、画二创、写吐槽
- **像素画/拼豆**——用 Aseprite 和 Pixel Studio 画图，偶尔做拼豆
- **AI 生成图像**——用 Omnibot 的 `gpt-image-gen` 和 `nano-banana` 技能快速出图

这三个兴趣有一个共同痛点：**每个兴趣都需要一整套「创作 → 发布 → 互动」流程**。

以前我的流程是这样的：

```
画完像素画 → 截图 → 打开小红书 → 写文案 → 加话题 → 发布
画完AI图  → 存本地 → 打开微博 → 写文字 → 发布 → 手动回复评论
看龙骑新集 → 想到吐槽 → 打开备忘录 → 手写 → 等有空再发
```

每一步都有「切换成本」：关掉这个 App，打开那个 App，找文件，写文案，想话题标签。

一个月下来，我大概能坚持发 4-5 条内容，然后就开始倦怠。

**倦怠不是因为没灵感，而是因为「发布」这件事本身太累了。**

## 二、把「发布」变成零操作

我的解决方案是：把所有能自动化的「非创作」环节全部交给 Agent。

### 2.1 微博自动发布

我用 `weibo-hub` 技能搭了一套自动化流程：

```python
# 伪代码：创作完成后自动发布
def publish_to_weibo(image_path, text):
    from weibo_hub import post_status
    post_status(image_path=image_path, status=text)
```

关键设计：**文案模板 + 自动话题标签**。

```python
HASHTAGS = ["#像素画#", "#AI绘画#", "#假面骑士龙骑#"]

def generate_caption(topic, mood):
    return f"{mood}来了张新图 ✨\n主题：{topic}\n\n" + " ".join(HASHTAGS)
```

这样我画完图，只需要告诉 Agent「今天画了一个假面骑士龙牙像素版，心情不错」，它就能自动生成文案并发布。

### 2.2 小红书批量操作

`xiaohongshu-hub` 技能让我能做到：

- 一键发布图文笔记（3:4 封面 + 多张作品图）
- 自动回复评论区互动
- 批量收藏感兴趣的素材

实际效果：以前一周才能发 1 条小红书，现在一周能稳定发 3-4 条，而且**发布动作本身耗时接近零**。

### 2.3 AI 生成图像的自动化

这个最有意思。我现在有一个固定流程：

```
1. 手绘像素画草稿（20-30 分钟）
2. AI Agent 调用 gpt-image-gen 生成高清封面版
3. 自动裁切成 3:4 小红书比例
4. 写入待发布队列
5. 定时发布
```

用一个 JSON 文件管理「待发布队列」：

```json
{
  "pending": [
    {
      "title": "假面骑士龙牙像素版",
      "image": "articles/2026-08-18-kamen-rider-longya.png",
      "platforms": ["weibo", "xiaohongshu"],
      "status": "ready"
    }
  ]
}
```

Agent 每天定时检查这个队列，按平台规则分发。

## 三、HN 热点：语音 Agent 的「模型选型」问题

说到自动化，今天 Hacker News 上有个项目叫 [Speko](https://news.ycombinator.com) 挺有意思。

它解决的问题是：**语音 Agent 需要 STT（语音转文字）+ LLM + TTS（文字转语音）三层模型，每层有十几个供应商可选，每次新模型出来都要重新评测。**

创始人 Bek 之前在亚洲做企业语音 Agent 四年，每次换模型都要「雇母语评测员 → 跑 benchmark → 对比数据 → 切生产」。他做的 Speko 把这个流程变成了 API：你传优化目标（准确率/延迟/成本），它自动选最优模型组合。

**这个思路其实和我的「生活效率实验」是同一个底层逻辑**：

| Speko 解决的问题 | 我的版本 |
|---|---|
| 语音模型选型太烦 | 内容发布流程太烦 |
| 每月有新模型要评测 | 每周有新灵感要发布 |
| API 自动选最优组合 | Agent 自动跑发布流程 |

**核心都是：把「选择」和「执行」从人手里挪走，让人只做最有价值的那一步。**

## 四、实际数字：省了多少时间

让我算一笔真实的账。

### 优化前（每周）：

| 活动 | 耗时 |
|---|---|
| 画像素画 | 3 小时 |
| AI 生图调试 | 1 小时 |
| 写文案+选图 | 1.5 小时 |
| 多平台发布 | 2 小时 |
| 回复评论互动 | 1 小时 |
| **合计** | **8.5 小时** |

其中「创作」只占 4 小时（47%），剩下 4.5 小时（53%）全是行政杂活。

### 优化后（每周）：

| 活动 | 耗时 |
|---|---|
| 画像素画 | 4 小时（画得更多了） |
| AI 生图调试 | 1 小时 |
| 告诉 Agent 要发什么 | 10 分钟 |
| 偶尔手动回复评论 | 20 分钟 |
| **合计** | **5.5 小时** |

**创作占比从 47% 提升到 84%，总耗时减少 35%。**

省下来的 3 小时，我用来干嘛了？

- 1.5 小时：补了《假面骑士龙骑》新集数的设定资料
- 1 小时：学了新的像素画技法（动态帧）
- 0.5 小时：折腾 AI Agent 写博客文章

## 五、我的方法论：「三步自动化法则」

经过这半年的折腾，我总结了一个通用法则：

### 第一步：识别「重复 + 低价值」的动作

问自己一个问题：**「如果这件事每周要做 5 次以上，我有没有想过自动化它？」**

我的答案清单：

- ✅ 社交媒体发布 → 已自动化
- ✅ 博客定时写文 → 已自动化（GitHub Action + Jekyll）
- ✅ 文件备份到云盘 → 已自动化
- ⏳ 拼豆配色方案生成 → 待自动化
- ❌ 假面骑士追剧 → 不想自动化（这是享受）

### 第二步：用「模板 + 队列」代替「即时操作」

不要每次做事都从零开始。用一个标准化的数据格式：

```json
// 任何待办都变成一条 JSON
{
  "action": "publish",
  "platform": "weibo",
  "content": "今天画了...",
  "priority": "normal"
}
```

Agent 消费队列，你只管生产。

### 第三步：定期复盘，把「手动」降级为「自动」

每月一次，列出这个月所有手动做的重复操作，问自己：**「这个能不能写成 50 行 Python 脚本？」**

能写的写，不能写的找现有 skill 解决。

## 六、最后的话：效率不是目的，热爱才是

我搞这些自动化的最终目的，不是为了「做更多事」，而是为了**把时间留给真正让我兴奋的事**。

画一张假面骑士龙牙的像素画，从 32×32 的草图开始，一点点填色，看它从几个方块变成一个能认出来的角色——这个过程，我不想让 AI 帮我做。

但「把这张图发到微博和小红书」这件事——我可以。

**这就是我和 AI 的分工：AI 做我不喜欢的事，我专心做我喜欢的事。**

今天 HN 上 Speko 的故事也在说同样的事：让机器去选型、去评测、去切换模型，让人专注于「我要用这个语音 Agent 解决什么真实问题」。

技术不是魔法，但用好技术能让生活变得魔法一点点 ✨
